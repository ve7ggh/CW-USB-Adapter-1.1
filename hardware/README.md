# Hardware

## Overview

This directory contains the complete open-source hardware design for the VE7GGH CW USB Adapter.

The design is based on the Adafruit TRRS Trinkey open-source hardware and has been substantially modified to create a board specifically intended for USB CW paddle interfacing and other USB HID applications.

The hardware has been developed to be fully reproducible. Source files and manufacturing data are included to allow others to study, modify, manufacture, and improve the design.

## Contents

This directory may contain:

- EasyEDA Pro project files
- Schematic source files
- PCB layout files
- Gerber manufacturing files
- Drill files
- Bill of Materials (BOM)
- Pick-and-Place (CPL) files
- PDF schematics
- Hardware documentation
- Images and renderings

## Derivative Design

This hardware is derived from the following open-source project:

**Adafruit TRRS Trinkey PCB**

https://github.com/adafruit/Adafruit-TRRS-Trinkey-PCB

Major modifications include:

- New PCB layout
- Redesigned board outline
- Custom silkscreen artwork
- Modified routing
- Updated component placement
- Project-specific hardware changes
- Removal of Adafruit trademarks and branding
